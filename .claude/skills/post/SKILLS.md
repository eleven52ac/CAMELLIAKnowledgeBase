# 技术笔记生成提示词模板

## 一、优化已有笔记

```
这是我的 {主题} 学习笔记，请根据以下定位优化补充：

笔记定位：面向个人知识库和技术博客，读者是有 Java 后端基础的开发者。

格式要求：
- YAML frontmatter（title / category / tags / published / updated / draft）
- Obsidian callout 语法（> [!tip] / > [!warning] / > [!warning] ⚠️）
- 章节用 ## / ### 分级，不超过三级
- 代码块注明语言，关键行加注释
- 对比内容用表格，流程用 ASCII 示意图

优化方向：
- 补充"是什么"的概念介绍（如果原笔记缺失）
- 补充与上下文章节的关联（承上启下）
- 关键 API / 注解单独说明，不只贴代码
- 补充生产环境注意事项或常见踩坑点
- 末尾加速查表或总结

以下是我的原始笔记：
{粘贴笔记内容}
```

## 二、从零生成新笔记

```
请为我生成一篇关于 {主题} 的技术学习笔记。

背景：我已学习过 {前置知识}，本篇是 {系列名称} 的第 {N} 篇。

笔记定位：面向个人知识库和技术博客，读者是有 Java 后端基础的开发者。

内容要求：
1. 概念介绍：是什么、解决什么问题、适用场景
2. 与前置知识的关联或对比（如果有）
3. SpringBoot 实现代码（完整可运行，关键行加注释）
4. 生产环境注意事项 / 常见踩坑
5. 末尾速查表

格式要求：
- YAML frontmatter
- Obsidian callout 语法
- 代码块注明语言
- 对比用表格，流程用 ASCII 示意图
- 不使用外部图片链接
```

## 三、生成系列大纲

```
我想学习 {技术名称}，已有基础：{已掌握的相关知识}。

请为我生成一份学习大纲，要求：
- 按学习顺序排列，循序渐进
- 每个章节一行，说明核心内容
- 不包含与已有基础重复的内容
- 控制在 6~8 个章节，不要过于细碎

后续我会按大纲逐篇生成笔记。
```

------

## 四、让风格保持一致的追加指令

在系列笔记的后续篇中，加上这句话保持风格延续：

```
请保持与前几篇相同的笔记风格：
- YAML frontmatter 格式一致
- callout 使用 [!tip] 和 [!warning]
- ASCII 示意图代替外部图片
- 末尾保留速查表
- 代码示例使用与前几篇相同的包名和命名风格
```

------

## 五、核心原则总结

| 原则             | 说明                                        |
| ---------------- | ------------------------------------------- |
| 明确定位         | 告诉 AI 笔记给谁看、用在哪里                |
| 提供样本         | 把已有笔记贴给 AI，自动对齐风格             |
| 说明补充方向     | 比"优化一下"更具体，效果更可控              |
| 约定固定格式     | callout、表格、ASCII 图，建立惯例后自动延续 |
| 大纲先行         | 先确认结构再逐篇生成，避免方向跑偏          |
| 迭代而非一次生成 | 单篇质量优于一次生成整个系列                |
