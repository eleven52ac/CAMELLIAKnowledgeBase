## Java 学习大纲

### 第一阶段：Java 基础

**1. Java 概述与环境搭建**

- JDK / JRE / JVM 的区别
- 环境安装与配置（IDEA）
- Hello World 与程序结构

**2. 基本语法**

- 数据类型（基本类型 / 引用类型）
- 运算符与表达式
- 流程控制（if / switch / for / while）

**3. 数组**

- 一维 / 二维数组
- Arrays 工具类

**4. 方法**

- 方法定义与调用
- 方法重载
- 可变参数

---

### 第二阶段：面向对象

**5. 类与对象**

- 类的定义、构造方法、this 关键字
- 封装、getter / setter

**6. 继承与多态**

- extends、方法重写、super
- 向上转型 / 向下转型
- instanceof

**7. 抽象类与接口**

- abstract class vs interface
- 接口默认方法（Java 8+）
- 多接口实现

**8. 常用类**

- String / StringBuilder / StringBuffer
- Math / Random / System
- 包装类与自动拆装箱

---

### 第三阶段：进阶特性

**9. 异常处理**

- 受检异常 vs 非受检异常
- try / catch / finally / throws
- 自定义异常

**10. 泛型**

- 泛型类 / 泛型方法 / 泛型接口
- 通配符（? extends / ? super）
- 类型擦除原理

**11. 集合框架**

- List（ArrayList / LinkedList）
- Set（HashSet / TreeSet / LinkedHashSet）
- Map（HashMap / LinkedHashMap / TreeMap）
- Collections 工具类
- HashMap 底层原理（数组 + 链表 + 红黑树）

**12. 迭代器与 for-each**

---

### 第四阶段：函数式与流式编程（Java 8+）

**13. Lambda 表达式**

- 函数式接口（Function / Predicate / Consumer / Supplier）
- 方法引用

**14. Stream API**

- 创建流 / 中间操作 / 终止操作
- filter / map / sorted / collect
- 并行流

**15. Optional**

- 避免 NullPointerException
- orElse / map / ifPresent

**16. 新时间 API**

- LocalDate / LocalTime / LocalDateTime
- DateTimeFormatter
- Duration / Period

---

### 第五阶段：IO 与网络

**17. IO 流**

- 字节流 / 字符流
- 缓冲流 / 转换流 / 打印流
- 序列化与反序列化

**18. NIO**

- Buffer / Channel / Selector
- 与 BIO 的区别

**19. 网络编程**

- Socket / ServerSocket
- TCP vs UDP

---

### 第六阶段：并发编程

**20. 多线程基础**

- Thread / Runnable / Callable
- 线程生命周期
- sleep / join / interrupt

**21. 线程安全**

- synchronized（方法锁 / 对象锁 / 类锁）
- volatile 关键字
- 死锁与避免

**22. JUC 并发包**

- ReentrantLock / ReadWriteLock
- CountDownLatch / CyclicBarrier / Semaphore
- ConcurrentHashMap / CopyOnWriteArrayList
- BlockingQueue

**23. 线程池**

- Executor / ExecutorService / ThreadPoolExecutor
- 核心参数（coreSize / maxSize / 队列 / 拒绝策略）
- Callable + Future / CompletableFuture

---

### 第七阶段：JVM

**24. 内存模型**

- 堆 / 栈 / 方法区 / 程序计数器
- 对象创建与内存分配

**25. 垃圾回收**

- 引用类型（强 / 软 / 弱 / 虚）
- 可达性分析
- GC 算法（标记清除 / 复制 / 标记整理）
- 垃圾收集器（G1 / ZGC）

**26. 类加载机制**

- 加载 / 验证 / 准备 / 解析 / 初始化
- 双亲委派模型
- 自定义类加载器

**27. JVM 调优**

- 常用 JVM 参数
- 内存溢出排查（OOM）
- 工具（jstack / jmap / jvisualvm / Arthas）

---

### 第八阶段：新特性（Java 11 ~ 21）

**28. 常用新特性**

- var 类型推断（Java 10）
- 文本块 Text Block（Java 15）
- Record 类（Java 16）
- sealed class（Java 17）
- 虚拟线程 Virtual Thread（Java 21）
- 模式匹配 instanceof（Java 16）

---

### 推荐学习路径

```
基础语法
   └──▶ 面向对象
           └──▶ 集合 + 泛型 + 异常
                    └──▶ Java 8 新特性（Lambda / Stream）
                               └──▶ 并发编程
                                       └──▶ JVM 原理
                                               └──▶ 新版本特性
```
