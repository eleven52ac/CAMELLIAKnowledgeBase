# 03 · 函数与异常

## 函数:比 Java 灵活很多

```python
def add(a, b):
    return a + b
```

### 默认参数(Java 要靠重载才能实现)

```python
def greet(name, greeting="Hi"):
    return f"{greeting}, {name}"

greet("Tom")              # Hi, Tom
greet("Tom", "Hello")     # Hello, Tom
```

> [!warning] 经典大坑
> 默认参数**别用可变对象**(如 `[]`、`{}`)。它只在定义时创建一次,会被多次调用共享。
> ```python
> def bad(item, lst=[]):   # ❌ 危险
>     lst.append(item)
>     return lst
> def good(item, lst=None): # ✅ 正确写法
>     if lst is None:
>         lst = []
>     lst.append(item)
>     return lst
> ```

### 关键字参数:调用时能乱序

```python
def connect(host, port, timeout):
    ...
connect(port=8080, host="localhost", timeout=30)  # 顺序随便,可读性高
```

### 函数是「一等公民」

可以当参数传、赋值给变量、塞进列表:

```python
def apply(fn, x):
    return fn(x)

double = lambda n: n * 2     # lambda 跟 Java 的差不多
apply(double, 5)             # 10
```

## 异常处理:try / except

关键字和 Java 不一样:`except` 不是 `catch`,`finally` 一样。

```python
try:
    result = 10 / 0
except ZeroDivisionError as e:
    print(f"除零了: {e}")
except (ValueError, TypeError):   # 一次抓多种
    print("值或类型错误")
else:
    print("没出错才执行")          # Java 没有这个
finally:
    print("一定执行")
```

### 主动抛异常

```python
def set_age(age):
    if age < 0:
        raise ValueError("年龄不能为负")   # 用 raise,不是 throw
```

### 对照速记

| Java | Python |
|------|--------|
| `try` | `try` |
| `catch` | `except` |
| `finally` | `finally` |
| `throw` | `raise` |
| `throws`(方法签名) | 无,Python 不强制声明 |

> [!note] 哲学差异:EAFP
> Java 习惯先检查再做(LBYL),Python 更推崇「先做,错了再抓」(EAFP — Easier to Ask Forgiveness than Permission)。直接 try 往往比一堆 if 判断更地道。
