# 01 · 基础语法与变量类型

> [!tip] 给 Java 仔的一句话
> 把 Python 想成「脱掉西装的 Java」——不用编译、不用分号、不用大括号、不用声明类型。它更随便,但也更容易在运行时翻车。

### 1. 缩进就是语法

Java 用 `{}` 圈代码块,Python 用**缩进**(统一 4 个空格)。没有分号,没有大括号。

```python
def greet(name):
    if name:
        print(f"Hi, {name}")
    else:
        print("Hi, stranger")
```

> [!warning] 最容易踩的坑
> 空格和 Tab 混用会直接报错。让编辑器把 Tab 自动转成 4 空格,一劳永逸。

### 2. 变量

```python
x = 10          # 不写 int,运行时才知道是啥
x = "现在是字符串"  # 同个变量还能换类型,Java 直接编译报错
PI = 3.14       # 没有 final,全大写只是「约定」表示常量
```

类型注解是**可选的**,只给人和 IDE 看,不强制:

```python
name: str = "Tom"
age: int = 30
```

### 3. 类型对照表

| Java               | Python  | 备注                       |
| ------------------ | ------- | ------------------------ |
| `int` / `long`     | `int`   | Python 整数**无限大**,不会溢出    |
| `float` / `double` | `float` |                          |
| `String`           | `str`   | 单引号双引号都行                 |
| `boolean`          | `bool`  | 注意首字母大写:`True` / `False` |
| `null`             | `None`  |                          |

### 4. `f-string`字符串拼接

相当于 Java 的 `String.format`,但顺手 100 倍:

```python
name, age = "Tom", 30
print(f"{name} is {age} years old")        # Tom is 30 years old
print(f"明年 {age + 1} 岁")                  # 大括号里能写表达式
print(f"{3.14159:.2f}")                     # 保留两位小数 → 3.14
```

### 5. 真值判断

空容器、`0`、`None`、空字符串都算 `False`:

```python
if not my_list:        # 列表为空时成立,不用写 list.isEmpty()
    print("空的")
```
